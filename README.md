# Sports de raquettes par sexe

Application EPS indépendante : listes de classes, montée-descente, poules filles/garçons, rencontres et historique HTML.

## Déploiement Vercel

Framework : Vite. Build Command : `npm run build`. Output Directory : `dist`.

Données conservées dans le navigateur via localStorage. Ne pas effacer les données du navigateur sans avoir exporté les bilans.

Ce dépôt ne contient pas le module « Partenaire en or ».
